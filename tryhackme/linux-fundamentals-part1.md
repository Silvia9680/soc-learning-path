# Linux Fundamentals Part 1
**Plataforma:** TryHackMe  
**Categoría:** Linux / Fundamentos  

## ¿De qué trataba?
Introducción al sistema operativo Linux, su estructura y comandos básicos.
Cubre la navegación por el sistema de archivos y operaciones fundamentales
desde la terminal.

## Conceptos clave aprendidos
- Estructura del sistema de archivos en Linux
- Comandos básicos de navegación: ls, cd, pwd, mkdir, rm
- Lectura y manipulación de archivos: cat, less, find, grep
- Permisos de archivos y usuarios en Linux

## Herramientas / técnicas mencionadas
- Terminal de Linux
- Comandos de búsqueda y filtrado
- Sistema de permisos (chmod, chown)
