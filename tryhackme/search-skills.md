# Search Skills
**Plataforma:** TryHackMe  
**Categoría:** SOC / Fundamentos  

## ¿De qué trataba?
Introducción a las técnicas de búsqueda efectiva de información aplicadas
a la ciberseguridad. Cubre cómo encontrar información relevante sobre
amenazas, vulnerabilidades y actores maliciosos de forma eficiente.

## Conceptos clave aprendidos
- Técnicas de búsqueda avanzada (Google Dorks y similares)
- Cómo buscar información sobre vulnerabilidades y CVEs
- Uso de fuentes de Threat Intelligence públicas
- Importancia de verificar y validar la información encontrada

## Herramientas / técnicas mencionadas
- Motores de búsqueda avanzada
- Bases de datos de vulnerabilidades (CVE, NVD)
- Fuentes OSINT para investigación de amenazas
